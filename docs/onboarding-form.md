# Lumora — User Onboarding Form

We collect onboarding details and product feedback from users through a **Google Form**.
Responses flow into a linked Google Sheet, which is exported to Excel for analysis and
record-keeping.

🔗 **Live form:** https://forms.gle/8jM5kg7TBzSxitu98

## Questions

1. **Your Name** — short answer (required)
2. **Email** — short answer (required)
3. **Stellar Wallet Address** — short answer (required)
4. **How would you rate Lumora?** — linear scale 1–5 (required)
5. **What works well, and what should we improve?** — paragraph (optional)
6. **I use Lumora primarily as a…** — multiple choice: *Employer / Employee / Other* (optional)

Responses are exported to [`lumora-user-feedback.xlsx`](lumora-user-feedback.xlsx), which also includes
an **Analysis** sheet (rating distribution, KPIs, themes) and a **Wallet Activity (testnet)**
